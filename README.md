# Excel AutoFill (APK)

1. Giải nén, đẩy toàn bộ lên một repo GitHub mới (nhánh main).
2. Vào tab Actions, đợi "Build APK" xanh, tải file ExcelAutoFill-APK (app-debug.apk) ở mục Artifacts.
3. Cài APK, mở mục Drive trong app và làm theo "Cách kết nối" (dán mã Apps Script 1 lần).

Khóa ký nằm trong signing/debug.keystore nên cài bản mới đè lên bản cũ không mất dữ liệu.
