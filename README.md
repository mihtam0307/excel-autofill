# Excel AutoFill (APK)

1. Tạo repo GitHub **Public**, đẩy toàn bộ project lên nhánh main.
2. Tab Actions: đợi "Build APK" xanh. APK nằm ở mục Releases (ExcelAutoFill.apk).
3. Cài APK, mở mục Drive: làm "Thiết lập Google Cloud" 1 lần, dán Client ID, bấm Đăng nhập Google.
4. Mỗi lần push code mới, Actions tự build; app tự báo "Có bản mới" khi mở.
